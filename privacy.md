📄 Política de Privacidade – App Fiscal

Última atualização: 06/02/2025

1. Introdução

O App Fiscal é um aplicativo desenvolvido para uso exclusivo dos fiscais da Empresa de Desenvolvimento Urbano e Habitacional – EMHUR, destinado à execução de atividades operacionais como autuações, vistorias e registros de campo.

Esta Política de Privacidade descreve como tratamos os dados necessários para o funcionamento do aplicativo, em conformidade com a Lei Geral de Proteção de Dados Pessoais (LGPD – Lei nº 13.709/2018) e com as políticas da Google Play.

2. Dados coletados pelo aplicativo

O App Fiscal coleta apenas os dados estritamente necessários para o desempenho das funções institucionais da EMHUR.

2.1. IDs de usuário

Identificador do fiscal utilizado para login e autenticação.

Usado para registrar qual agente realizou cada operação dentro do sistema.

2.2. Localização exata

Coordenadas geográficas obtidas durante autuações, vistorias ou registros de campo.

Usadas para validar o local das ações e anexar informações ao processo administrativo.

2.3. Fotos (opcional)

Imagens capturadas pelo usuário para complementar registros de vistorias e autuações.

O envio de fotos é opcional, porém, quando realizado, é vinculado ao processo correspondente.

O App Fiscal não coleta:

Nome pessoal

Endereço de e-mail

Lista de contatos

Arquivos pessoais

Mensagens

Cookies ou dados de navegação

Informações biométricas

Dados sensíveis (raça, religião, saúde etc.)

3. Finalidade do tratamento dos dados

Os dados coletados são utilizados exclusivamente para:

Funcionalidade essencial do aplicativo, permitindo o registro e execução das atividades de fiscalização.

Composição de autos de infração, vistorias e demais documentos oficiais.

Garantia da segurança, rastreabilidade e integridade das informações operacionais.

O aplicativo não utiliza dados para:

publicidade

marketing

perfis comportamentais

personalização de conteúdo

análises externas

4. Compartilhamento de dados

O App Fiscal não compartilha dados com terceiros.

Todos os dados coletados são enviados exclusivamente aos sistemas internos da EMHUR, que atua como controladora dos dados conforme a LGPD.

Nenhuma informação é compartilhada com empresas privadas, anunciantes, plataformas externas ou parceiros comerciais.

5. Armazenamento e segurança dos dados

Todas as informações transmitidas são protegidas por criptografia em trânsito (HTTPS).

Os dados são armazenados apenas nos servidores institucionais da EMHUR.

São adotadas medidas técnicas e administrativas para prevenir acessos não autorizados, perda ou alteração indevida dos dados.

6. Retenção e exclusão dos dados

Os dados armazenados pelo App Fiscal fazem parte de documentos oficiais, incluindo:

Autos de infração

Vistorias

Evidências fotográficas

Registros operacionais

Por essa razão:

❗ O usuário não pode solicitar a exclusão desses dados pelo aplicativo.

A retenção e eventual exclusão seguem normas administrativas da EMHUR e legislações aplicáveis ao serviço público.

7. Direitos dos titulares de dados

Em conformidade com a LGPD, os usuários podem solicitar informações sobre:

categorias de dados tratados

finalidade do tratamento

medidas de segurança

controlador responsável

Solicitações devem ser direcionadas à EMHUR.
